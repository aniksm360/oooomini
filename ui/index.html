What is what

Profile isolation: separate cookies, storage, cache per session (real).
Device emulation: viewport, DPR, touch, user-agent (emulated, not a physical device).
Network isolation: only if you configure a proxy you are authorized to use for that session; otherwise all sessions share this PC's connection.
Public IP: what an external service observes for that session, verified live, never assumed.
